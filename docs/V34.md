# V34: actual-codec supervised adaptive preprocessing

`RGB → source detections + causal motion/context → CNN/GRU controller → bounded six-coefficient spatial filter → H.264/H.265 → independent decoder → frozen task heads`.

The controller buffers one 16-frame GOP and chooses one of 13 actions. Region maps use only the current and earlier source frames, reset at scene cuts, and preserve geometry. The filter changes spatial frequency bands, without averaging moving RGB over time. The identity action is exact in 8-bit RGB. Encoder-only region maps are not transmitted: the standard receiver only needs the paid bitstream/header.

Offline training first measures every action with real x264/x265. The cached targets are packet rate relative to the same-QP anchor and each active task's loss change. Gradient updates enter the CNN/GRU/action/risk/rate heads only. There is no STE, differentiable codec or learned restoration in V34. Missing tasks are masked. Candidate targets use per-task damage constraints rather than trading away one task for another.

CAL uses 16 held-out TRAIN-domain sources per AR/OD domain, with no optimizer updates. Empirical one-sided residual bounds control selection. These bounds are exploratory calibration, not a distribution-free guarantee over correlated QP conditions. The rate bound permits up to 1% more bits to preserve near-equal-rate quality gains; an actual-byte check rejects an oversized chosen packet. Each seed's forced classifier output and deployed selection are reported separately, including Q8 edits, identity/fallback counts, raw curves and timing. CAL oracle labels remain in the measurement cache; TEST ground truth never selects a candidate.

Two public jobs each train three seeds (303401/303402/303403), using QP30/35/40/45/50 on H.264/H.265, medium preset, 25fps, closed GOP16 without B-frames or scene-cut insertion. COCO images use GOP1. AR clips follow the historical center/stride2 recipe at 128px; COCO is letterboxed to 320px; MOT20 to 640px. Frozen MobileNet detector preprocessing is locked to min_size320/max_size640 for both measurement and deployed OT. Frozen Swin3D-T is the AR training/evaluation head. R3D-18 and ResNet50 are transfer evaluators for AR/OD.

AR+OD uses K400 clip labels and COCO boxes. K400 OD supervision is source prediction/feature consistency; there are no object labels on those clips. COCO single images have no AR supervision. AR+OT uses K400 plus MOT20-02 TRAIN/CAL, MOT20-03 DEV and MOT20-01 TEST, first256 frames. MOT20-02 windows1–192 train and193–256 calibrate. Window-local GT box/ID cost is a training surrogate; deployed ByteTrack keeps state for all256 frames, and pinned official TrackEval reports HOTA/IDF1/MOTA. TEST/DEV GT is read only after stream selection. MOT20 AR reports source KL and no action accuracy. K400 OT uses source-track consistency, with no tracking GT.

These are multi-domain exploratory pilots, not a joint-label AR+OT benchmark. AR/OD TEST uses64 sources per domain, DEV16, TRAIN48. Splits inherit previously explored dataset partitions; gains cannot be treated as an untouched final benchmark. AR has paired video bootstrap accuracy intervals at the same QP. OD/OT intervals are null in this initial pilot; one OT sequence per split prevents a sequence bootstrap. BD-rate is reported only for valid overlapping curves and is not an improvement claim. Larger independent cohorts, joint-label JRDB-Act and OT appearance-model transfer remain necessary follow-ups.

Payload validation recompiles/rebuilds the exact recipe and hashes its committed source. Public payloads contain source/origin/job only, never pool credentials or pretrained checkpoints. Submit records its intent before networking so a timeout cannot trigger a blind duplicate. Submission receipts and links are retained in the workspace. Completion monitoring is left to the user.

Deployment cost in this pilot includes source detection and an anchor encode for the byte check. A nonidentity proposal needs a second encode, although only the accepted packet is transmitted. Timing separates source support, diagnostic source teachers, candidate filtering, encoding, decoding and receiving. This is not yet a single-encode low-cost controller.
