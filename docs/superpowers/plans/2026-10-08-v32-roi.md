# V32 ROI Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox syntax for tracking.

**Goal:** Deliver a runnable V32 ROI simplification/retarget benchmark with real packet accounting and optional frozen V30-B hybrid.

**Architecture:** New `adaptive_vcm/v32` package; leave historical modules unmodified. Fixed ROI geometry, serialized reconstruction recipe, real-codec adapter, guarded arm selection and dataset evaluation are separate units.

**Tech Stack:** Existing NumPy/OpenCV/PyTorch/FFmpeg/pytest; Python>=3.10; no new dependency.

**Spec:** `docs/superpowers/specs/2026-10-08-v32-roi-design.md`.

## Global constraints

- QP30/35/40/45/50; H.264/H.265; guard .1 AR/.03 OD; anchor saving .01.
- No GT/evaluator in selection; original frozen V30-B loader; all required metadata counted.
- Scene-stable mapping and original-source rate denominator; no new trainable expert.
- Separate checkout and output; no GPU submission; no synthetic quality claims.

## Review focus

- Disjoint scene cuts must not mix motion/layout across scenes (geometry tests).
- Empty/full ROI must not invent useful retargeting (geometry/selection tests).
- Same RGB with different mapping must not share reconstructed teacher predictions (packet selection tests).
- Malformed packet lengths/CRC/grid must fail before uncontrolled allocation/decode (transport tests).
- Frozen checkpoint TRAIN source or upstream drift must fail closed (baseline tests).
