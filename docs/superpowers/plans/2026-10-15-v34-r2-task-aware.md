# V34 R2 task-aware preprocessing implementation

> **For agentic workers:** Use superpowers:executing-plans and test-driven-development.

**Goal:** Implement the accepted OD/OT improvements and a single-packet AR+OD+OT mode, keeping R1 AR reproducible.
**Architecture:** Opt-in `adaptive_vcm.v34r2` package reuses the 13 bounded filters, real codecs and frozen heads. New maps, detached dual targets, controller and transactional tracker state stay separate from V34 R1.
**Tech Stack:** Python, NumPy/OpenCV, PyTorch, pinned supervision ByteTrack and TrackEval, FFmpeg x264/x265.
**Spec:** `../output/od_ot_method_literature_20261015/METHOD_DECISION.md` and the accepted three-task preprocessing discussion.

## Global Constraints

- Four QPs 30/35/40/45, both codecs, the original 13 actions and three seeds. No codec gradient or TEST-driven tuning.
- Legacy AR code/config/checkpoints remain untouched. Joint mode is a new model, never three old checkpoints combined.
- Source-only deployment; independent GT and consistency masks. A single COCO image cannot supervise AR or OT.
- Every OT candidate forks the same selected prefix; only the chosen fork commits. Independent state per split, sequence, codec, QP, arm and seed. Candidate order must not matter.
- Historic K400/COCO/MOT cohorts remain exploratory. No claim of improved mAP/HOTA without full real-data experiments.
- Local implementation, smoke measurements and immutable runnable payload preparation are authorized. Record separately whether any expensive external run was launched.
